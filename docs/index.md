# Diário de um Dev

Bugs, soluções e curiosidades do dia a dia de quem programa.

Este é o meu caderno aberto: cada post nasce de um problema real que eu
enfrentei no meu próprio setup — Arch Linux, Hyprland, Caelestia-shell,
servidores, redes e automação. Nada aqui é tutorial decorado: é o registro do
que quebrou, de como eu achei a causa e do que resolveu.
