# Sobre

Oi, eu sou o **Jailson Silva** ([GitHub](https://github.com/jailsonh3)),
desenvolvedor e sysadmin Linux.

Criei este blog para ser o registro público do meu processo de resolver
problemas: quando algo quebra no meu ambiente, eu investigo até a causa
raiz, anoto o que descobri e a solução final — e publico.

## Como este blog funciona

Cada post é um arquivo Markdown em `docs/blog/posts/`, com data no nome e
front matter com categorias e tags. O site é gerado com
[Zensical](https://zensical.org/) e publicado no GitHub Pages a cada push na
`main`.

O critério de publicação é simples: **se eu resolvi o problema e vale a pena
lembrar em seis meses, vira post**. Não tem agenda, não tem revisão — tem
utilidade.
